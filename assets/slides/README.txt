ADD YOUR SLIDESHOW IMAGES HERE
==============================

1. Put JPG / PNG / WebP images in this folder.
2. Open ../data.js.
3. Add one line per image inside PORTFOLIO.slideshowImages:

   { src: "assets/slides/lab-01.jpg", label: "Full-scale structural testing" },
   { src: "assets/slides/field-01.jpg", label: "Field assessment" },

4. Save and open index.html.

The slideshow automatically rotates every ~5.2 seconds, supports previous/next controls,
and scales to additional images without changing app.js.
